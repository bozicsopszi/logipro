Ez egy nagyon kezdetleges, de egyszerű Electron alapú asztali alkalmazás, amely logisztikai technikus vizsgára való felkészülést segíti.
A program HTML, CSS és JavaScript technológiákkal készült, és célja, hogy egy alap, könnyen használható tanulási felületet biztosítson. Jelenlegi állapotában egy minimális funkciókkal rendelkező prototípus, amely később továbbfejleszthető kérdésbankkal, tesztekkel és egyéb tanulást segítő elemekkel.
A projekt célja a gyakorlás és az alapok elsajátítása Electron alkalmazás fejlesztésben, nem pedig egy kész, végleges szoftver.
